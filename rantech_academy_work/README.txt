RANTECH ACADEMY - SUPABASE CONNECTED STARTER

1. Open config.js.
2. Replace PASTE_YOUR_SUPABASE_PUBLISHABLE_KEY_HERE with your Supabase PUBLISHABLE key.
3. Do NOT put a Supabase secret/service_role key in this file.
4. Open signup.html to create a student account.
5. Log in and open dashboard.html.

The dashboard reads courses/modules/lessons from Supabase and reads the student's lesson progress.
The course page currently displays the course structure. Lesson completion UI will be added in the next build step.
